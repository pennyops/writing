# Carrusel: Conoce las Funciones Principales de 0xramp (borrador)

Carrusel de 6 imágenes (1080x1350 PNG, para X) en español para el bounty de Zcash en Español en ZecHub.

1. Presentación de 0xramp
2. Pay
3. Comprar/Vender
4. Swap
5. Actividad
6. Más

Archivos editables:
- `slides_es.md`: textos de cada imagen
- `render_slides.py`: plantilla HTML/CSS que genera los PNG (colores, tipografía y márgenes editables)

Capturas tomadas de https://0xramp.app con la app en español. Se aceptan cambios de texto, colores o formato.
